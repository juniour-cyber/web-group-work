1.Every group member must write and own their own JavaScript code for their individual profile page.
 Each member must be able to explain every line they wrote during the presentation.

2.Shared features (home page, contact page) must be built collaboratively
 — the Word document must state clearly who wrote which part of the shared code.

3.Use external .js files only. No inline JavaScript (onclick=, onload= attributes) 
and no <script> blocks inside the HTML body. All scripts must use the defer attribute.

4.No frameworks, libraries, CDNs, or external APIs. Pure Vanilla JavaScript only.

5.Comments are mandatory: every function must have a one-line comment explaining its purpose.
